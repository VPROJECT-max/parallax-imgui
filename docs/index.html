Typography Engine & Inter Font Hierarchy PHASE 3

Parallax completely replaces Dear ImGui's default bitmap font with the modern, high-legibility Inter font family. Fonts are rasterized on-demand for display DPI scaling with automatic fallback to Windows Segoe UI:

Inter Hierarchy

Structured weights: Regular (14px), Medium (14px), SemiBold (14px), Bold (15px), Title (18px), and Caption (11px).

DPI Auto-Scaling

Ratios adjust glyph rasterization dynamically. Calling RebuildFonts(dpiScale) hot-reloads the DirectX 11 GPU texture atlas without restarting.

Scoped Font RAII

Convenient helper parallax::ScopedFont automatically pops font upon exiting scope, preventing ImGui font stack mismatches.

// Initialize typography engine during DirectX 11 startup:
parallax::Typography::Init(1.0f);

// In rendering code:
{
    parallax::ScopedFont font(parallax::FontWeight::Bold);
    ImGui::Text("Crisp Inter Typography");
}
// Or manual push/pop:
parallax::Typography::PushFont(parallax::FontWeight::Title);
ImGui::Text("Executive Summary");
parallax::Typography::PopFont();

Developer Key System & Licensing PHASE 4

A modular cryptographic authorization system designed for professional developer seat management and licensing. Features non-blocking asynchronous validation (zero frame latency impact), masked password inputs with show/hide eye toggle, and persistent license storage.

Asynchronous Non-Blocking Verification

Runs verification on a background worker thread with std::future. The UI stays at 60/144/240 FPS with physical harmonic spinner animation.

Persistent Machine Licensing

Stores validated credentials locally with optional auto-login on startup. Provides clear Success (emerald) and Error (crimson) banners.

// 1. Configure custom verification callback:
auto& keySys = parallax::auth::KeySystem::Get();
keySys.SetVerifier([](const std::string& key) -> bool {
    // Check against your remote licensing API or crypto signature:
    return key.rfind("PRLX-", 0) == 0 && key.length() >= 10;
});

// 2. Open branded modal dialog or inspect auth state:
if (!keySys.IsAuthenticated()) {
    keySys.RenderModal(&showModal);
}

JSON Configuration Engine & Profile Manager PHASE 4

Production-grade, schema-driven configuration management built on nlohmann/json. Supports stable variable identifiers, type-safe bindings for all Parallax widget types, profile management (Default, Legit, Rage), and atomic disk persistence.

Atomic Disk Writes

Writes configuration to .tmp file before replacing the target .json profile. Eliminates corrupted configuration files caused by crashes or sudden power termination.

Debounced Auto-Save

Automatically triggers debounced disk writes 1.5 seconds after any setting change, minimizing disk I/O while ensuring state persistence.

// 1. Bind variables with stable string keys during initialization:
auto& cfg = parallax::config::ConfigManager::Get();
cfg.BindBool("visuals.box_esp", &boxEsp, true);
cfg.BindColor("visuals.box_color", &boxColor, ImVec4(0.388f, 0.400f, 0.945f, 1.0f));
cfg.BindKeybind("aim.trigger_key", &triggerKey);
cfg.BindFloat("aim.fov", &fovValue, 90.0f);

// 2. Save, load, or render full Profile Manager UI:
cfg.SaveProfile("Legit_Tournament");
cfg.LoadProfile("Legit_Tournament");

// In your settings tab:
cfg.RenderConfigTab();

Declarative Chaining API C++20

Inspired by Rayfield's developer experience, Parallax allows you to express rich, multi-control settings rows in a single readable chain: 

// Clean declarative syntax — compiles with 0 allocations per frame
parallax::Row("Bounding Box Overlay", &boxEnabled)
    .Icon("eye")
    .Description("Draw crisp dynamic 2D/3D bounding boxes")
    .Tooltip("Toggles bounding boxes around detected targets")
    .Keybind(&boxKey)
    .Color(&boxColor)
    .OnChange([](bool enabled) {
        printf("Bounding Box toggled: %s\n", enabled ? "ON" : "OFF");
    });
Automatic Move-Semantics Rendering: The temporary parallax::ControlRow object created by parallax::Row(...) automatically renders itself upon destruction at the semicolon. Zero boilerplate, zero dangling references, and full RAII safety.

Inline Keybind System

Parallax provides a compact keyboard hotkey button designed to fit natively inside control rows without disrupting layout:

Modes & State Evaluation

Supports Hold, Toggle, and AlwaysOn modes. Evaluates keyboard keys and mouse buttons (VK_LBUTTON, VK_RBUTTON, VK_MBUTTON, VK_XBUTTON1/2).

Input Capture Safety

While the keybind popup is listening for a key, the global Parallax menu hotkeys (Right Shift / Insert) are suppressed, preventing the menu from closing prematurely.

parallax::Keybind myKey{ 'F', parallax::KeybindMode::Toggle, false };

// Inside render loop:
parallax::UpdateKeybindState(myKey);
if (myKey.active) {
    // Hotkey is active!
}

// Inline widget rendering:
parallax::KeybindWidget("##MyKeybind", &myKey);

CMake Quick Start

Targeting modern C++20 with zero manual dependency installation:

# CMakeLists.txt
cmake_minimum_required(VERSION 3.20)
project(MyParallaxApp LANGUAGES CXX)

set(CMAKE_CXX_STANDARD 20)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

add_subdirectory(parallax-imgui)

add_executable(MyApp main.cpp)
target_link_libraries(MyApp PRIVATE parallax)

DirectX 11 Host & Input Module

The parallax::dx11::D3D11Host module handles Win32 window message loops, swap chain recreation, and safe buffer resizing:

Safe WM_SIZE Resizing

Releases render target views prior to ResizeBuffers and cleanly reconstructs views to prevent DXGI texture leaks or crashes.

Typing Safety (VK_RSHIFT)

When ImGui::GetIO().WantTextInput is active, VK_RSHIFT toggle events are filtered so capital typing functions without closing the menu.

// Customizing toggle hotkeys
parallax::AddToggleKey(VK_RSHIFT, /*ignoreWhenTyping=*/true);
parallax::AddToggleKey(VK_INSERT, /*ignoreWhenTyping=*/false);
